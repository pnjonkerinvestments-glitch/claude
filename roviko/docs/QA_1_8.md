## Scope and intentional choices

- No solo time limit, score or XP was reintroduced.
- No payment system, unrestricted chat, compulsory reminder or tracking SDK was added.
- The site's existing visual identity and original game artwork are retained; numeric fact hierarchy, freshness/date copy and clue-type status improve the puzzle surface.
- Native private rooms use the same server authority as the website. Native offline practice is explicitly separate from server statistics.
- Historical raw daily data remain in storage. Only the Mosaic fact presentation is upgraded; answers are not rescored and country matches do not change.
