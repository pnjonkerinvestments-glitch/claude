# Verification — Roviko website 1.11.0

Date: 24 September 2026. This release includes the published 1.10 Spanish/multiplayer/map update and adds official daily competition. Source provenance for the Claude download is in its `EXPORT_MANIFEST.json`.

## Automated gates

- `npm run typecheck`: passed.
- `npm run build`: passed; Vinext produced the Worker, client assets, hosting metadata and all Drizzle migrations.
- `npm test`: 103 tests passed, zero failed.
- `git diff --check`: passed.

The tests use actual isolated Workerd/D1 bindings and WebSocket pairs for backend integration, React-rendered components for interaction behavior, and the built Worker for initial HTML/CSS checks. They are not screenshots or physical-device tests.

## New competition coverage

- Five modes each cap at 1,000 points, with no speed bonus and zero practice points.
- Clue Trail varies continent options, capital is third, flag fourth, no answer-option flags, and self-revealing capitals are excluded.
- Paid clue state survives reload, cannot be refunded, and private flag access is denied before hint 4 and for other users.
- Duplicate concurrent answers have one winner; client-supplied scores are ignored.
- World Trip map credit is normalized into its 200-point round.
- Rank statistics and comparison solutions/values are absent before submission and revealed afterwards.
- Mosaic hides unsolved tile associations and fact sources, identifies actual mismatches, charges hints and forfeits a mistaken anchored group's points.
- Mosaic/comparison competition components wait for authoritative feedback while practice remains immediate.
- First completed daily results persist once; retries and fresh practice cannot farm points.
- Ties share rank, zero scores count as participation, and blocked users are excluded.
- Daily and cumulative totals have separate date scopes; invalid ranking queries are rejected.
- Guest/account merge retains the account's first daily, transfers other scores once, revokes the guest session and cascades on account deletion.
- Export includes the ledger. Legacy unranked native/API sessions preserve their old contracts and do not receive retroactive scores.
- Initial production HTML contains all five daily cards, the scorecard, six practice modes and the original Roviko branding.

The suite also retains multiplayer rooms/reconnect/rematch/host permissions, 12-player capacity, exact-answer locking, Spanish translation coverage, map pinch/pan/tap separation, explicit ordering confirmation and earlier puzzle/progress tests.

## Environment limitation and remaining checks

The supervised browser preview infrastructure was unavailable (`sites-previewd mailbox is unavailable`). No substitute browser server was started. This release does **not** claim visual browser QA, actual 320–1920 px viewport screenshots, iPhone/Safari pinch verification, VoiceOver/E2E or production load testing. Perform these on real browsers/devices after publication. The pointer interaction tests use simulated SVG events and do not replace physical touch testing.

The source still contains the pre-existing native iOS project in the repository, but the website-only ZIP excludes `ios/`. No Xcode compile, native competition opt-in, signing or App Store submission was performed. Google OAuth requires the owner's provider credentials for live validation.

## Migration / operational notes

`drizzle/0003_gorgeous_arachne.sql` adds the bounded, indexed `daily_scores` ledger; all older migrations remain intact. The deployment archive includes it. Existing historical daily content/results remain preserved and unranked. No production users/test fixtures are seeded by the test suite. Anonymous identities are resettable; the rankings are not a verified-human or cheat-proof competition system.
